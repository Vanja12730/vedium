# Repository instructions

## Commit and pull request attribution

- Use the repository owner's configured Git identity for AI-assisted commits.
- Do not add AI assistants or vendors (including Claude, Anthropic, Codex,
  OpenAI, Copilot, or other bots) as authors, co-authors, or contributors.
- Omit AI `Co-Authored-By` trailers and "Generated with" or similar AI-credit
  footers from commit messages and pull request descriptions.
- Before committing or publishing, check the outgoing messages and remove any
  AI attribution. Preserve legitimate human attribution, licence notices,
  and the contributor sign-off required by CONTRIBUTING.md.
- Keep existing published history intact unless the owner authorizes rewriting
  it to remove attribution.
